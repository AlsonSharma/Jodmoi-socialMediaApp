## 🚀 Project Highlights
- **Dynamic User Profiles** with CRUD operations
- **Social Interactions**: Post likes/comments & connection requests
- **Live Resume Builder** with PDF generation
- **Secure JWT Authentication** system
- **File Uploads** with Multer middleware
- **SEO-friendly** Server-side Rendering (SSR)

## 💡 Why I Built This
*"Jodmoi emerged from my fascination with social platforms and practical tool integration. I aimed to create a space where users not only connect socially but also build professional resumes organically through their platform activity, combining community engagement with career development."*

## 🏁 Getting Started (Local Setup)

1. **Clone Repository**
   ```bash
   git clone https://github.com/AlsonSharma/Jodmoi-social-platform.git

2. **Install Dependencies**
**Frontend**
```bash
cd frontend
npm install
```
**Backend**
```bash
cd backend
npm install
```

3. **Configure Environment**
Create .env files using provided .env.example templates

4. **Launch Development Servers**
**Backend**
```bash
cd backend && npm run dev
```

**Frontend (in new terminal)**
```bash
cd frontend && npm run dev
```
